FEMEngine is a header-only C++ library for solving continuum mechanics problems by the finite element method. The variational formulation is written in code in a form close to mathematical notation, and the stiffness matrix is assembled from the weak form with the functional programming and template metaprogramming features of modern C++. The package was tested on the Poisson equation.

The package was presented at the Ivannikov ISPRAS Open Conference (2019) and registered as computer software (registration No. 2019664165).
