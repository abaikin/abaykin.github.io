Заведующий лабораторией программных систем оптимизации добычи углеводородов Новосибирского государственного университета / Head of the Laboratory of Software Systems for Hydrocarbon Production Optimization, Novosibirsk State University (https://www.nsu.ru/).

**Основной источник фактов:** `ForCLAUDE/резюме_Байкин Алексей Николаевич_2026.docx` (черновик, будет улучшен). В `ForCLAUDE/` лежат и другие материалы; то, что нужно публиковать «как есть», копируй в `assets/` (подробные правила в `CLAUDE.md`).

### Publications / Публикации
- Источник данных: единый BibTeX-файл (`src/data/publications.bib`), из которого строится страница; возможность скачать полный `.bib`. Доп. поля (теги, тип, индексация, аннотации, путь к fulltext) хранить в нестандартных полях BibTeX или в сопутствующем YAML. Предложи вариант и обоснуй.
- Для каждой записи: выходные данные, DOI и/или ссылка на онлайн-ресурс, индексация (РИНЦ / Scopus / WoS и т.п.), аннотация, теги, кнопка **BibTeX** (копирование записи в буфер обмена), ссылка на fulltext (PDF загружу позже: пока файла нет, кнопка скрыта).
- По дефолту показывать списком публикаций без аннотации. Аннотация выдвигается чуть ниже при нажатии на Подробнее / Details.
- Также нужны кнопки для копирования bibtex строки для аннотации и строки для цитирования (для вставки в документы типа word)
- Аннотации: хранить на языке оригинала; для другого языка интерфейса показывать перевод (если перевода нет, делается черновой машинный перевод с пометкой `auto`).
- Разбивка по годам, с указанием, где индексируется публикация. Навигация по годам.
- Поиск (название, авторы, аннотация, теги) и сортировка по годам (по возрастанию/убыванию).
- Фильтры: по типу (публикации в журналах / результаты интеллектуальной деятельности / тезисы докладов и труды конференций / прочие), по индексации, по тегам. Фильтры сочетаются и отражаются в URL.
- Теги задаю я как владелец сайта.
- У тезисов и материалов (трудов) конференций сделать ссылку на соотвествующее выступление.

## Референсы

Изучи их вживую (открой, посмотри вёрстку и стили) и в плане кратко опиши, что именно берёшь из каждого.

1. https://academic-demo.netlify.app/ (Hugo Blox, Academic CV)
   - Нравится: страница Bio, тема Default (можно ее цветовую гамму взять как для темной так и для светлой темы), анимации и выделение блоков, кнопка Download CV, формат и вид раздела Experience.
   - Не нравится: остальные разделы перегружены и сделаны «в стиле блога».
2. https://sajalsharma.com/posts/
   - Взять шрифты для английского языка (определить по CSS сайта; для русского подобрать подходящие кириллические аналоги и согласовать со мной).
   - Нравится список статей; для блога сделать нечто подобное, но с картинкой.
   - Для списка публикаций (Papers) нужен другой вид, не как здесь.
3. https://github.com/NicolasMeseguer/nicolasmeseguer.github.io
   - Нравится оформление списков статей и кнопка BibTeX. Там возможно на самом гите лежит какой-то другой сайт, но вот раньше было как на картинке ForCLAUDE/frame_0069.png - по каждой статье оформление неплохое. Можно с него начать, но потом добавить еще элементов, если потребует тахническое задание. Автор мог поменять сайт: смотри исходный код и историю репозитория.
4. https://astro.build/themes/details/academic-portfolio-astro
   - Нравится минимализм, теги на все темы, компактные карточки с кнопкой View для деталей.

Идея для шапки главной: анимация развития трещину гидроразрыва. Пока наверное не делаем - слишком трудоемко. Потом может быть.

1. Каркас: Astro, i18n, темы, шрифты, навигация, деплой на GitHub Pages (Actions). Страница Bio.
2. Papers (BibTeX, поиск, фильтры, теги, кнопка BibTeX).
3. Talks.
4. Experience (работа, проекты и гранты, образование, студенты, достижения, skills).
5. Projects (отдельные страницы), Laboratory (заглушка), Courses.
6. Blog (LaTeX, видео, интерактивные графики, Jupyter), Hobby.
7. SEO (sitemap, RSS, OG, schema.org Person / ScholarlyArticle), доступность, производительность (Lighthouse), финальная проверка обоих языков и обеих тем.

## Критерии готовности

- Сайт собирается без ошибок и публикуется на GitHub Pages.
- Оба языка и обе темы работают на всех страницах, на десктопе и мобильных.
- Телефон нигде не встречается (проверено поиском по репозиторию).
- Добавление новой публикации / выступления / записи блога делается правкой одного файла данных.
- В итоговом отчёте перечислены все `TODO` и пробелы в данных.
